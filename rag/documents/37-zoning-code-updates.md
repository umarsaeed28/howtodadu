# Zoning Code Updates

> Team notes from a Seattle builder's talk, not the Seattle Municipal Code. Figures are not verified against the current SMC. Mark them unverified when you rely on them, and always separate what the code allows from what the market supports.

Also called: backyard cottage, DADU, detached accessory dwelling unit, detached ADU, middle housing.

## The 2019 rules
Under the 2019 rules a single-family lot could have the main house plus one attached ADU and one detached ADU (DADU). Each ADU was capped at 1,000 sq ft.

## ADU size increase
Under the newer code a DADU can be 20% larger, up to 1,200 sq ft. That is enough for a three-bedroom floor plan.

## By-right density
The newer code allows 4 to 6 units by right on almost any standard lot in the Neighborhood Residential zones.

## Type A accessibility exemption
If the first floor is fully accessible (Type A), density can go up to 10 units on a lot.

## What the code allows versus what sells
These are maximums. A lot that can legally hold 6 or 10 units may not support that many in the current market. Check demand and real construction cost before planning to the maximum.
